# Monarch Studio

A single-file static landing page. The styling, mobile navigation, and hero artwork are all contained in `index.html`; there are no build steps or runtime dependencies.

## Preview locally

Open `index.html` in a browser, or serve the repository root with any static server, for example:

```sh
python3 -m http.server 8000
```

## Customize

Edit the copy, colors, and sections directly in `index.html`. The contact section intentionally says “Contact details coming soon” until a real contact method is supplied. The hero artwork is embedded in the page, so the deployed website does not need a separate image file.
